# Learning Resources

Use external training sites within their terms and stay inside their provided labs. A link is a starting point, not an endorsement or a substitute for checking current course content and cost.

| Topic | Resource | Practice goal |
| --- | --- | --- |
| Linux and SSH | [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) | Practice shell navigation, permissions, processes, and SSH in the game environment. Keep your own notes; avoid publishing level passwords. |
| Shell puzzles | [CMD Challenge](https://cmdchallenge.com/) | Solve command-line tasks with small, understandable pipelines. |
| Git concepts | [Oh My Git!](https://ohmygit.org/) and [Learn Git Branching](https://learngitbranching.js.org/) | Practice commits, branches, merges, rebases, and recovery in a sandbox. |
| Kubernetes | [Kubernetes documentation](https://kubernetes.io/docs/) and [K8s Games](https://k8sgames.com/) | Pair interactive exercises with the official reference documentation. |
| Security fundamentals | [TryHackMe](https://tryhackme.com/) | Use only authorized rooms and training targets; focus on defensive understanding and remediation. |
| Programming | [CodeCombat](https://codecombat.com/) | Build basic Python or JavaScript fluency through guided exercises. |
| Containers | [Docker documentation](https://docs.docker.com/) | Build, inspect, run, and secure a small container image. |
| GitOps | [Argo CD documentation](https://argo-cd.readthedocs.io/) | Understand reconciliation, health, sync, and rollback semantics. |

## Suggested weekly rhythm

1. Choose one skill and define a concrete outcome.
2. Spend one session learning, then one session reproducing the task without the tutorial.
3. Write a short note: what failed, how you diagnosed it, and what you would automate.
4. Review the note with a peer or explain it aloud. Update your next goal based on what remains unclear.

Use the [Practice-to-Proof lab](practice-to-proof-lab.md) to turn one external lesson into a reproducible work sample, with an [example completed record](practice-to-proof-answer.md). Do not copy third-party lesson content or answers into this repository.
